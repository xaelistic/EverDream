b) What users love vs want

1 Temenos Dream

Jungian AI + Circles. Sacred / depth-psych dream work; AI as reflective companion (not a horoscope dictionary); privacy + optional sharing.

Loved

  • Voice capture → text so you don’t fully wake to write
  • Chat-style AI (follow-ups, associations, symbols)
  • Jungian / myth / archetype framing (“harder” introspective prompts)
  • Nightmare reframing; “bridge until I can afford therapy”
  • Encryption / private-by-default, then optional share

Want / pain

  • Export should include full AI chat, not just interpretation notes
  • Mobile typing bugs, long-text UI, transcription glitches
  • Price pushback (~$50–60/yr premium)
  • Occasional “too much / busy” UI

Recency: Reviews and changelog into 2025–mid 2026; Android bugs being fixed live; still growing, not stagnant.

2 DreamApp (“Dream”)

Mainstream AI meanings + therapist angle + heavy growth marketing.

Loved

  • “Spookily accurate” AI when users write long, specific dreams
  • Life / PTSD / pattern connections; conversational AI
  • Volume of content and multi-language reach

Want / pain (loud)

  • Billing / free-trial / cancel issues dominate negatives
  • Price + aggressive paywall
  • Trust damage from support non-response stories
  • Android rating dragged (~3.7) despite strong iOS score

Recency: Still huge, but sentiment is polarized — scale without trust is a liability EverDream can avoid.

3 Oniri

“#1 dream app” — journal + AI analysis + lucid practice stack (reality checks, audio cues, WBTB, MILD, SSILD, FILD…). Site claims 300k+ dreamers.

Loved

  • Beautiful, sticky journal UX (people finally leave paper behind)
  • Voice notes + transcription, images (search + generate), drawings
  • Stats: emotions, people, symbols, trends, nightmare analysis
  • Lucid tools that “actually help”
  • Passcode / privacy, PDF export, widgets
  • Long-term users (years of entries)

Want / pain

  • Android lagging iOS (layout/keyboard, free tier, ~3.9★)
  • Heavy paywall for interpretation / lucid / multi-image
  • Dictionary/symbol coverage gaps (older reviews)
  • Reality-check notifications unreliable (being fixed)
  • Richer dream categories (lucidity spectrum, custom types)

Recency: Highest ship velocity in this set (nightmare analysis, trends, re-recorded audio, widgets in Jul 2026). Strong “most actively competitive” signal.

4 LucidMe

REMspace / Raduga orbit — lucid / OBE practice + in-app social network + optional hardware mask.

Loved

  • Community / dream sharing as a first-class feature
  • Techniques library; free research-style content
  • Social proof (likes, activity, challenges)

Want / pain

  • Reply / conversation notifications (users miss threads for days)
  • Accessibility (tiny text, dark mode)
  • App freezes, reinstall loops
  • Mask / hardware frustration ($200, false cues, forced registration)
  • Support feels offline

Recency: Social product is actively expanding (activity + notifications for likes/comments/follows; rating-based feed; clans; dream mates; challenges; streaks).

Deep dive: Temenos “feed” (and what to steal for EverDream)

Temenos is not primarily a global TikTok of dreams. From product copy + founder interviews, sharing is layered:

  1. Private by default (encrypted journal)
  2. Share with one person
  3. Dream Circles — small groups for discussion (human-powered, not algorithm-first)
  4. Optional public post so others can comment
  5. Broader “public wall” / messaging mentioned in 2025 roundups

So the model is closer to “intimate circles + optional public wall” than Discord-or-bust. That maps well to replacing a Discord-centric community:

Discord pain Temenos-style alternative EverDream opportunity
Context switch, new app Stay inside journal after capture Share this dream → Feed / Circle in one tap
Noisy / off-topic Circles you choose Circles: friends, cohort, “nightmares only,” etc.
Hard to link a dream Share is a first-class dream object Feed post = dream card (image, nugget, themes) + privacy tier
Moderation chaos Smaller rooms + public optional Default private / friends / circle / public
No product loop Share after AI insight Prompt: “Share interpretation?” vs raw narrative only

LucidMe’s feed lessons

What users explicitly ask for if you build social:

  • Reply notifications and conversation continuity
  • Readable typography / accessibility
  • Sort modes (recent vs rating / quality)
  • Light social objects: likes, comments, follows, “similar dreams,” optional challenges/streaks
  • Avoid coupling community to hardware or forced phone signup

Temenos lessons

Higher trust for EverDream’s brand:

  • Circles before infinite public feed
  • Jungian / reflective framing of comments (“what does this image mean to you?”) not hot takes
  • AI stays personal; humans add resonance
  • Privacy defaults that are easy to explain

Strategic takeaways for EverDream

Most popular right now

  • DreamApp wins raw popularity.
  • Oniri wins “best-in-class journal product people recommend and keep.”
  • Temenos wins trust and depth among a smaller, high-intent cohort.
  • LucidMe is the clearest proof that in-app social/feed is a real product direction — if notifications and UX work.

Features that move the needle (love)

  1. Instant morning voice capture
  2. Good AI that feels personal + follow-up chat
  3. Images
  4. Patterns over time
  5. Optional community that doesn’t force leaving the app

Features that lose trust (avoid)

  1. Dark-pattern trials / hard cancel (DreamApp)
  2. Android half-baked (Oniri)
  3. Social without notifications (LucidMe)
  4. Overwhelming UI / capture bugs (Temenos mobile complaints)
Feed vs Discord — recommendation

Build a Temenos-shaped social layer, not a Discord clone:

  1. Privacy ladder: Private → Friends → Circle → Public
  2. Dream-native posts: card with image + short nugget + themes (not a chat dump)
  3. Circles first (small, intentional), public feed second
  4. Activity + reply notifications (LucidMe’s #1 ask)
  5. Optional “similar dreams” / resonance matching (LucidMe already ships this)
  6. Keep Discord as optional power-user space, not the home of community

That combination is rare: DreamApp/Oniri are weak on intimate community; LucidMe is strong on social but weaker as a polished journal; Temenos has the right social philosophy but limited scale. A journal-first app with Circles + light public feed is a clear white space — and a direct upgrade path off Discord-centric community.
